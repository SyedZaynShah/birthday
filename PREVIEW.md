## Typography

**Serif (Playfair Display)**:
- Used for: Headings, letter, elegant text
- Style: Classic, romantic, sophisticated

**Sans-serif (Inter)**:
- Used for: Body text, UI elements
- Style: Clean, modern, readable

---

## Animations

All animations are **subtle and elegant**:

✓ Envelope opening (1s smooth unfold)
✓ Section fade-ins (0.8s gentle)
✓ Card hover lift (slight upward movement)
✓ Flower gentle sway (3s loop)
✓ Candle sequential lighting (0.05s delay each)
✓ Parallax bouquet (follows cursor on desktop)

❌ No jarring movements
❌ No excessive confetti
❌ No rainbow explosions
❌ Respects prefers-reduced-motion

## Responsive Design

### Mobile (320px - 767px)
- Single column layout
- Larger tap targets
- Bouquet stays centered and large
- Text remains readable
- Envelope fits comfortably

### Tablet (768px - 1023px)
- Two-column card grid
- Medium spacing
- Balanced layout

### Desktop (1024px+)
- Three-column card grid
- Generous whitespace
- Parallax effects enabled
- Maximum elegance

✨ **Static Export** - Can be hosted anywhere
